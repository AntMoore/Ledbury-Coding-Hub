# Getting Started with VS Code

This guide will walk you through installing Visual Studio Code and setting it up to run the HTML and JavaScript examples from the Ledbury Coding Meetup.

---

## 🧠 What is Visual Studio Code?

[Visual Studio Code](https://code.visualstudio.com) (VS Code) is a free code editor made by Microsoft. It's popular with developers because it's lightweight, powerful, and works on Windows, Mac, and Linux.

For our sessions, we'll be using it to:
- Open and edit the example code
- Run HTML pages using a browser
- View your JavaScript output in the developer console

It's a great tool for learning, and many developers use it professionally too.

---

## 🧩 3. Install Live Server Extension

In VS Code, you can add extra features by installing **extensions**. These are small plugins that add useful tools to your editor — kind of like installing apps on your phone.

For this project, we recommend installing an extension called [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer).

Live Server is used to:
- Open your HTML file in a browser with just one click
- Automatically refresh the page every time you save a file
- Save you from manually reloading the browser or reopening the file every time you make a change

This makes it much easier to test and experiment while learning.

---

### 🔧 To install Live Server:

1. Click the **Extensions** icon on the left side of VS Code (or press `Ctrl+Shift+X`)
2. In the search bar, type `Live Server`
3. Find the one by **Ritwick Dey**
4. Click **Install**

Once it's installed, you'll see new options like **"Open with Live Server"** when right-clicking an HTML file.

![Screenshot of Visual Studio Code with the Live Server extension by Ritwick Dey selected in the Extensions panel](/Assets/live-server-extension-example.png)

---

## 🚀 4. Run a Demo

1. In the folder list, open one of the lesson folders — for example: [JavaScript/01-console-log/index.html](/JavaScript/01-console-log/index.html)
2. Right-click `index.html` and choose **"Open with Live Server"**
3. Your default browser should open and display the page
4. Press `F12` to open the developer console and see the output

---

## 🔄 5. Make a Change

Try editing `script.js` or the text in `index.html`, then save the file. The browser will automatically reload with your changes.
